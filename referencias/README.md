# Referencias: plantillas ya utilizadas

Carpeta para depositar documentos que ya hayas usado o recibido (políticas, contratos, RAT, protocolos) y que sirvan para **pulir la estructura** de las herramientas del portafolio.

## Cómo usarla

1. **Anonimiza antes de subir**: reemplaza nombres, RUC, cédulas, correos y cualquier dato de clientes o personas por `[MARCADORES]`. Esta carpeta nunca debe contener datos reales.
2. Guarda el archivo en la subcarpeta que corresponda:
   - `rat/` — registros de actividades de tratamiento
   - `plantillas/` — políticas, avisos, contratos, cláusulas, comunicaciones del DPD
   - `vulneraciones/` — protocolos, bitácoras, notificaciones
3. Pide a Claude Code: *"Compara las referencias de `referencias/plantillas/` con nuestras plantillas y propón mejoras de estructura"*. Claude propondrá los cambios; tú decides cuáles se incorporan.

## Origen y derechos

Anota en `origen.md` de dónde proviene cada referencia. Las referencias de terceros sirven para estudiar su estructura; no se copia su redacción.
