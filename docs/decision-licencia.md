# Decisión pendiente: licencia para la versión pública

Elegir antes de cambiar el repositorio a público.

| Opción | Efecto | Encaje con tu objetivo |
|---|---|---|
| CC BY 4.0 | Cualquiera puede usar y adaptar, incluso comercialmente, citándote | Máxima difusión y autoridad; competidores pueden reutilizar |
| CC BY-NC 4.0 | Uso libre con atribución, sin uso comercial | Difusión con protección frente a reventa; el límite "comercial" es discutible en la práctica |
| CC BY-ND 4.0 | Se comparte tal cual, sin modificaciones | Protege tu redacción, pero reduce la utilidad como plantilla |
| Sin licencia (todos los derechos reservados) | Visible, pero sin permiso de reutilización | Sirve como vitrina, no como recurso abierto |

Recomendación preliminar: publicar una versión **genérica** con CC BY 4.0 (vitrina y autoridad) y mantener privadas las versiones completas que usas con clientes.
