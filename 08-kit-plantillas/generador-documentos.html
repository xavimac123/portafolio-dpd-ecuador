Editar plantilla:

Corrige o mejora el texto. Usa [MAYÚSCULAS ENTRE CORCHETES] para los datos variables y > al inicio de línea para notas internas. Los cambios se guardan en este navegador; usa “Copiar Markdown” para incorporarlos al repositorio.

Importar plantilla propia

Pega el texto de un documento que ya uses (desde Word) o sube un archivo .md o .txt. Reemplaza los datos variables por [MAYÚSCULAS ENTRE CORCHETES] y el generador creará un campo para cada uno.
